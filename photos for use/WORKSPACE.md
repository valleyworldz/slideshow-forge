# photos for use — Elite workspace

This folder is the **canonical photo library** for Slideshow Forge. All E2E tests and elite workflows use it.

## Elite approval

```bash
npm run elite:approve
```

## Elite workflow (desktop — recommended)

```bash
npm run electron:dev
```

Loads this folder automatically. Export → pick USB or `output/`.

## Elite workflow (CLI)

```bash
npm run workspace:scan
npm run workspace:export
```

## Output

Exports land in `output/Samsung_Slideshows/Elite_Slideshow/` with numbered JPEGs, optional MP4, manifest, and TV README.

## Notes

- ~188 JPGs — full MP4 takes several minutes; folder export ~8 min on typical hardware
- Use **exFAT** USB for TV copy
- `workspace.project.json` is regenerated by `workspace:scan` (safe to delete)
